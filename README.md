# WebRTS Native

Standalone offline-first real-time strategy game for Windows and Android.

Built in Godot 4 with an angled low-poly 3D battlefield, integrated game menus, and native gameplay UI.

Development follows the 132-slice master roadmap in `docs/ROADMAP-NATIVE-OFFLINE-1.0.md`.

The original [WebRTS browser prototype](https://github.com/AlmightyTank/WebRTS) remains a separate reference project.

## Getting started

Install a pinned Godot 4 stable version (see `docs/DEVELOPMENT.md` once added), open `project.godot`, and run the project with F5. Gameplay requires no local or hosted web server.
