# Asset conventions

The native game loads locally packaged assets only. Do not reference CDN URLs.

- `models/`: original low-poly 3D units, buildings and environmental props (prefer imported GLB/GLTF).
- `textures/`: tileable terrain, decals and surface maps (size-budgeted).
- `ui/`: native UI icons, silhouettes, cursors and game HUD images.
- `audio/`: licensed original music, voices, SFX and ambience.

Keep the original source/author/license information for every imported asset.
Only placeholder art is present in Slice B. Art/content pipelines arrive later.
